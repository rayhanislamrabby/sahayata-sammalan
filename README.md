# Sahayata Sammalan – Charity Platform

A professional social organization website built with a modern Next.Js.

## 🚀 Live Demo
[https://sahayata-one.vercel.app](https://sahayata-one.vercel.app)

## 🛠️ Features
- **Modern UI:** Responsive and high-end design for all devices.
- **Animations:** Smooth UI transitions using Framer Motion.
- **Social Sharing:** Configured Open Graph (OG) metadata for professional link previews.
- **Deployment:** Automated CI/CD and custom domain setup via Vercel.

## 💻 Tech Stack
- **Framework:** Next.js, React
- **Styling:** Tailwind CSS
- **Animation:** Framer Motion
- **Hosting:** Vercel

---
### ⚙️ How to Run Locally
1. Clone the repo: `git clone <repo-url>`
2. Install dependencies: `pnpm install`
3. Run dev server: `pnpm dev`
